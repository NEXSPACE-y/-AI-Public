# 自律型サイバーAI防御システム（Public Showcase）

> **Public Showcase Package** — 外部会話型LLMやクラウドAPIに依存せず、完全ローカル完結で OS 監視・脅威検知・2段AI判定・自律隔離・監査記録・脆弱性診断を実行する次世代サイバー防御デスクトップシステムです。

- **公開リポジトリ**: https://github.com/NEXSPACE-y/-AI-Public
- **技術基盤**: Rust ネイティブバックエンド + Tauri v2 + React / TypeScript + ローカル非言語AI
- **初回対応OS**: Windows 11 / 10（実機 E2E 検証済み）・Linux（制御/パーサー単体テスト＆クロス型検査済み）

## システム設計・主要機能

1. **完全ローカル非言語AI 2段連携エンジン**
   - **処理AI（Isolation Forest）**: プロセス／TCP・UDP接続／静的ファイル構造の多次元特徴から異常度スコアをリアルタイム算出。
   - **判定AI（Jev型 MLP ＋ 決定論的キルチェーン相関）**: 異常スコアと固有指標を組み合わせ、プロセスを 3 段階（正常範囲／要注意・監視／危険候補）に判定し、疑わしい検体を 7 種類のマルウェアファミリーへ分類。
2. **境界・ファイル名ホワイトリストに頼らない深層フォレンジック**
   - 通信トポロジ監視（外部TCP確立数・ワイルドカード待受・既知C2／横展開ポート相関）。
   - PE32/PE64/ELF32/ELF64 バイナリ構造検査（`.pdf`/`.txt` 等への拡張子偽装 `T1036`、生サイズ `0` の中空実行セクション `T1027.002`、WX/パッカーセクション）。
   - 大容量ファイル（256KB超）に対する先頭＋末尾オーバーレイのハイブリッド走査、スクリプト難読化・シェルコード断片検出（`T1027`）。
3. **自律防御・隔離金庫・SHA-256 ハッシュチェーン監査証跡**
   - 悪性（`malicious`）検知時に関連非重要プロセスを保護ルール付きで停止し、隔離金庫へ自動退避（誤検知時はワンクリック復元）。
   - すべての観測・判定・防御操作を直前レコードの SHA-256 ハッシュで連結する改ざん検知付き監査ログ（排他ロックによる二重起動／不正書換防止）に記録。
4. **プライバシー保護学習 ＆ 日次自動精度補正**
   - ユーザー名・ホーム経路・秘密鍵/パスワード管理/ロックファイルを学習対象から完全除外。16件以上で自動学習し、日次公開時に評価精度が閾値（`85.0%`）を下回った場合は直前の安定モデルへ自動ロールバック。
5. **脆弱性・ツールチェーン監査 ＆ ひとことPC健康診断**
   - Rust / TypeScript 開発・運用環境の脆弱性監査と S〜D 総合診断スコア・ワンクリック改善提案、企業提出用監査レポート（Markdown / JSON）出力を提供。

## 留意事項（運用・検証境界）

- **OS別検証範囲**: Windows 11 環境では全機能の E2E 実機動作確認が完了しています。Linux 環境向け制御モジュールは単体テスト（40件）およびクロスコンパイル型検査まで完了していますが、Linux 実機でのネイティブ GUI E2E は未実施です。
- **多重起動の抑止**: 起動時に監査ログへの排他ファイルロックを取得するため、すでにアプリまたはトレイアイコンが稼働中に 2 つ目のプロセスを起動すると二重起動防止のため即終了します。
- **利用規程**: 評価・検証目的での利用や商用連携条件については [LICENSE_AND_POLICY.md](LICENSE_AND_POLICY.md) をご参照ください。
